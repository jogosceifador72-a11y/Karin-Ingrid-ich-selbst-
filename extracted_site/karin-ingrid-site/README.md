# Karin Ingrid — Website Starter

Static, responsive German-language website starter for Karin Ingrid. Includes the supplied portrait, editorial styling, a searchable/filterable e-book catalog, product detail route, social links, and legal-page placeholders.

## Preview locally
Open `index.html` in a browser. For best results use a local static server, e.g. `python -m http.server 8000` from this directory.

## Before publishing
- Confirm product-title mapping for `wasessenbei.vercel.app` and `wieman.vercel.app`.
- Review the overlap/relationship between the two heart-health links.
- Verify every external destination and replace any broken links.
- Add the final professional biography and credentials only after verification.
- Replace the legal placeholders with legally reviewed information matching the actual operator and hosting setup.
- Add article pages only after content is written and medically reviewed.
- Consider generating individual SEO pages and sitemap for the production deployment.

## Files
- `index.html`: main page and catalog
- `styles.css`: responsive design and visual system
- `app.js`: catalog filtering, search, navigation
- `produkt.html` + `books.js`: simple product detail template
- `impressum.html`, `datenschutz.html`, `haftungsausschluss.html`: legal draft pages
- `assets/karin-ingrid.png`: portrait supplied by the user

Note: This is a static starter, not a hosted/publicly deployed website. External destinations and legal content require review before publication.
